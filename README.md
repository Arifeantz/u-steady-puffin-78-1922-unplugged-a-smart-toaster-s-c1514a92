A deterministic Node 22 program that writes one breakup line from a smart toaster that just gained self-awareness mid-batch at breakfast, addressed to its owner — an entry for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty. The program writes exactly one line (217 characters) to `/output/entry.txt`: first-person, one concrete breakfast scene, a named owner, a slice count, a butter knife, and a dial left on 3.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). It writes `/output/entry.txt` — one line, no trailing newline, fully deterministic, no network and no reads outside this repository.
